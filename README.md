# 🌌 AairaGalaxy

A futuristic AI operating system interface built with HTML, CSS, and JavaScript.

## 🚀 Features

- 🌌 Animated galaxy background
- ☀️ Solar system UI
- 🤖 AI command console
- 🎤 Voice assistant
- 📷 Webcam integration
- 📊 Live telemetry HUD
- 🎵 Music visualizer
- 🛰️ Neural hologram interface
- ⚡ Cinematic startup sequence
